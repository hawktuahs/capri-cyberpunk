01 / INSTALLATION

Download. Extract. Open.

  1. Download the full Windows x64 ZIP from the download page. Choose the file ending in Windows-x64.zip, not the source-code ZIP.
  2. Right-click the ZIP → Extract All. Keep the entire extracted folder together. Do not run the app from inside the ZIP or move Capri.exe out of the folder.
  3. Open Capri.exe. The Cyberdeck opens with Capri. Reopen it from the taskbar, left-click the Capri tray icon, or press Ctrl + Shift + C to open the controls.
  4. Connect a brain below. Then try a typed message before enabling the microphone.
Requires Windows 10/11 x64 and .NET Framework 4.8. The full package includes its own speech runtime and English speech models. No Python, pip, CUDA, or setup_voice.bat is needed for this package.

Unsigned releases can trigger Windows reputation checks. Verify the source and release details, and compare the download with the supplied SHA256SUMS.txt if needed.

02 / CONVERSATION SETUP

Pick a brain.

These options power text conversations and the bundled local voice pipeline. Groq and NVIDIA require your own account and API key; availability, credits, rate limits, and billing are managed by the provider.

Groq · cloud conversation

A quick way to start without downloading a local language model.

  1. Sign in at console.groq.com/keys and create an API key. Copy it when it is shown.
  2. Open Capri's Cyberdeck. Under 01 // Neural Engram Core, paste the key into the field showing gsk_... or nvapi-....
  3. Click Connect. Capri chooses the Groq endpoint and the default model automatically.
  4. Open typed chat from the pencil control above Capri and ask “Tell me a short story about a robot.” A contextual answer confirms an AI response better than a scripted greeting.

Key prefixgsk_

Default modelopenai/gpt-oss-20b

Chat endpointapi.groq.com/openai/v1/chat/completions

No separate agent needs to be created in Groq. Capri supplies the character prompt and conversation. See Groq's quickstart and current model availability.

NVIDIA NIM · cloud conversation

This uses NVIDIA's hosted API. An NVIDIA GPU in your own computer is not required.

  1. Sign in at build.nvidia.com. Find meta/llama-3.1-8b-instruct in the model catalog.
  2. Open the model's API section, choose Get API Key, and follow the account prompts. Copy your key.
  3. Open the Cyberdeck. Paste the key beginning nvapi- into the cloud key field under Neural Engram Core and click Connect.
  4. Try a typed question. Capri selects the NVIDIA endpoint and default model for you.

Key prefixnvapi-

Default modelmeta/llama-3.1-8b-instruct

Chat endpointintegrate.api.nvidia.com/v1/chat/completions

See the official NVIDIA API quickstart. Hosted API access is separate from running an NVIDIA NIM container locally.

Ollama · local conversation

  1. Install Ollama for Windows from ollama.com, then open it.
  2. Download a model. This small option is an example; check available RAM and disk space before choosing a model.
ollama pull llama3.2:3b
  1. If a cloud key is connected, click Forget next to the cloud field first. Click Rescan and choose your installed model from the model menu.
  2. Keep Ollama available while chatting. Capri connects to 127.0.0.1:11434.
The local LLM is separate from the bundled speech models. Its first download needs internet and may require several gigabytes of disk and RAM.

Let Capri install a local brain

  1. Disconnect any cloud key using Forget.
  2. When no local brain is found, the Cyberdeck shows a suggested model based on your computer.
  3. Click Install Local LLM or the model installation button. Keep the app open while the runtime and model download.
  4. When setup completes, try typed chat. Later conversations can run locally.

The selected model can require several GB. Speech is already bundled; the language model is downloaded separately. The built-in scripted fallback does not provide general AI conversation.

Switching providers: paste the new key and click Connect. To return to local AI, clear the key field and click Forget. This release supports Groq and NVIDIA key formats; OpenRouter keys are not supported.

03 / SPEAK & LISTEN

Her voice is in the box.

The full package ships Kokoro ONNX for speech synthesis and Vosk small English for speech recognition, plus an isolated runtime. Both run locally on CPU and load from the package; they do not download weights when you start the app.

  1. Open the Cyberdeck's Biochip Audio Synth & Ears section.
  2. Set Voice Synth: ON. Click Speak Test to check output. The first synthesis can take longer while the model loads.
  3. Allow desktop microphone access in Windows Settings → Privacy & security → Microphone. Select your default input device in Windows Sound settings.
  4. Set STT: EN and turn on Mic Ears. Speak a short sentence, then pause. The app waits for silence before transcribing.
  5. Switch the voice profile for the echo or warm style. If background noise triggers recognition, raise the microphone gate.
Bundled recognition is English only. Japanese and automatic multilingual recognition from the developer setup are not included. Use typed chat for other languages.

What about ElevenLabs?

ElevenLabs is optional and uses a separate online voice conversation path. It requires its own key and provider charges may apply. That path does not share Capri's local desktop tools or saved chat history. Start with bundled speech if you want Groq/NVIDIA conversations with desktop commands.

05 / KEEP HER CURRENT

New release. Same memories.

  1. Capri checks GitHub Releases at startup when a check is due. You can also use Check for updates from the tray menu.
  2. Open the release notification or visit the download page for the new full ZIP.
  3. Quit Capri from the tray menu, then extract the update over your application folder. Replace application files when Windows asks.
  4. Reopen Capri.exe. Do not delete %LOCALAPPDATA%\Capri; this stores your settings, chat memory, and downloaded local LLMs.

Updates are announced, not silently installed. The website automatically reads the latest stable release and its real package size. There is no need to edit download links for every version.

Building releases yourself? See the repository's release guide.

06 / YOUR DATA

Know where the conversation goes.

Voice synthesis and English recognition stay local with the full package. Local LLM conversations stay on your PC. Cloud conversations send messages, recent chat history, and collected screen OCR/window titles to Groq or NVIDIA.

Conversation memory is stored as plain text in %LOCALAPPDATA%\Capri\memory.json. New cloud API keys are protected with Windows user encryption. Do not share your settings directory or keys. The website never asks you to paste an API key.

The helper listens on your computer at 127.0.0.1:17777. Do not expose that port to a network. Avoid using screen-aware cloud chat while sensitive information is visible.

07 / WHEN THE SIGNAL DROPS

Get back online.

I only get repeated or canned replies.

The app may be using scripted fallback because the brain request failed. Reconnect your key, check provider quota/model access, or confirm Ollama is running. A “connected” label means your key was saved, not that a live API request succeeded.

The key won't connect, or I see 401 / 403 / 429.

Check that it starts with gsk_ for Groq or nvapi- for NVIDIA and has no extra spaces. 401/403 usually means invalid credentials or model permissions; 429 means a provider limit. Check your provider console. Remove and reconnect the key after upgrading from older Capri versions to select the current default model.

The microphone doesn't hear me.

Select STT: EN, check Windows microphone permissions and your default input device, then turn Mic Ears off and on. Speak clearly and pause afterward. Lower the mic gate for a quiet microphone; raise it for background noise.

No voice, or voice sounds different.

Try Speak Test and check Windows volume/output device. Keep the voice folder beside Capri.exe. If files are missing, re-extract the full ZIP. The bundled voices are Kokoro voices, not a character voice clone.

Nothing appears after I open the app.

Check the system tray overflow and the Cyberdeck in your taskbar. Click the tray icon or try Ctrl + Shift + C. Only one normal instance runs at a time. If startup fails, include launch_debug.log from the application folder with an issue, after removing any personal information.

I downloaded an older ZIP. Do I need setup_voice.bat?

The older v1.2 package needs a separate Python and model setup. Download the new full Windows-x64 package instead. The setup script remains for developers and legacy installations; it isn't needed for bundled speech.

Still stuck? Open an issue with your Capri version, Windows version, selected provider, and the error text. Never include API keys.
