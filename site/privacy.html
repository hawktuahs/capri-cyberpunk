PROJECT CAPRI PRIVACY & DATA

Project Capri — privacy and data

Effective 1 November 2026. Publisher: regressorslove. This policy describes the Project Capri 1.9.0 Microsoft Store version. Earlier downloadable versions use different speech components and may have different controls.

Use and risk

Project Capri is experimental AI software. Speech recognition, generated replies and automated actions can be wrong or unexpected. Agent tools block arbitrary terminal commands and executable downloads; supported browser writes and Notepad appending require review. These application-level guardrails are not a security sandbox or a guarantee of safety. The application runs with your Windows user permissions. Review actions, keep backups and enable only the capabilities you need.

To the maximum extent permitted by applicable law, the software is provided as is, without warranties, and the publisher and contributors disclaim liability for losses or damage arising from its use. Non-waivable rights and liabilities remain unaffected. See use and liability notice for the full use and liability notice. This notice does not change the data practices described below.

Local processing

The microphone starts only when you enable Mic Ears or click Mic Test. Moonshine Small streaming recognizes English locally; the bundled Cactus Whistle engine handles the other supported languages. While awake and Mic Ears is enabled, recognized utterances are conversation requests and may be sent to your selected cloud provider. While asleep, wake mode requires “Capri”; rejected utterances stay local. Wake mode still needs microphone access while listening. Audio is processed in memory and short-lived local temporary files used by the recognizer, normally removed after recognition. Capri does not keep a library of microphone recordings.

Chatterbox Nano generates the Capri and ASMR voices locally from the prepared reference profiles included with the app. The complete source recordings are not uploaded by the app.

If the available memory budget prevents Nano loading, Capri can use an installed Windows voice as a clearly labelled local fallback. It does not download a voice or send reply text to a provider. The selected sampled profile remains saved. The Whistle path can use word probabilities to flag uncertain speech. English streaming returns provisional text for display and dispatches only finished lines. Neither path guarantees transcription accuracy. Retry notices are local text and are rate-limited to avoid speaking a retry back into the microphone.

Word papers, PowerPoint briefings and generated Notepad drafts use the requested public research excerpts and your selected conversation provider as described below. Exporting the reviewed .docx/.pptx is local; the files contain editable text and no macros, remote resources or executed code. Notepad writing requires a verified blank tab and exact-text review. These are AI drafts, not fact-checked papers. Idle messages and animation cycling are local and do not invoke an AI provider. The separately toggleable spoken idle reminders use only an already prepared local Nano voice; otherwise the reminder stays text. They never invoke ElevenLabs or start model preparation.

Optional providers

Selecting Groq or NVIDIA sends conversation text, recognized speech requests and recent conversation context to that provider. Connection setup identifies the provider. Their own privacy, retention and billing terms apply. Without a cloud brain, an installed local model can be used instead.

The optional Foundry Local connection sends conversation requests to a user-selected HTTP loopback server on the same PC, with no cloud API key. Capri rejects remote endpoints and redirects. The runtime and model are managed separately by that host; its own settings and logging still apply. No Foundry runtime, Phi Silica model or automatic Windows AI download is installed by this connection.

Selecting ElevenLabs sends spoken reply text to api.elevenlabs.io for speech synthesis using your own key and voice ID. It does not upload the bundled reference recordings. Chrome page-analysis replies use local speech even when ElevenLabs is selected, avoiding an additional disclosure of those replies to the speech provider.

Screen and Chrome

Browser questions/tasks use the selected conversation provider through a shared bounded tool protocol. A local model receives the visible accessibility snapshot on this PC; its host's logging policy still applies. Selecting Groq or NVIDIA requires a separate snapshot/destination approval before each page view is sent. There is no silent switch to a cloud provider. Page-derived answers bypass saved conversation history and use local speech. Browser actions retain their separate permission, exact-request and destination checks. Decorative window visits use window geometry and bundled artwork, without capturing application contents.

Screen access is off by default. Enabling it allows desktop window titles and OCR text to be included with conversation requests, including requests to a selected cloud brain. Turn it off to stop that collection.

Chrome access is separately off by default. Local page preview, text search, highlighting and accessible-element perching run on your computer. To analyze a page through Groq or NVIDIA, Capri displays the selected destination and a bounded snapshot of accessible page text. You must choose “Send this page once” for each snapshot. URL query strings and fragments are omitted. Password controls are excluded, but ordinary page text can still contain personal information; inspect the preview. Page snapshots and their analysis replies are not added to Capri's saved chat history. Page-analysis replies cannot execute model action tags.

Typing or pressing named Chrome elements requires action review. Sensitive and destructive targets are blocked. Capri does not provide a general shell, installer or arbitrary file-control tool to the agent.

With Safe actions enabled, explicitly requested Notepad appending reads the selected Microsoft Notepad tab locally to verify its identity and preserve existing text. A review shows the destination and exact text to append. The tab and document are checked again after approval. This does not save the document or execute its contents; Notepad's own draft/session retention settings can still retain the text. Direct Notepad action requests do not need a conversation-provider call.

Storage and controls

With Safe actions enabled, named Calculator/Notepad button requests inspect the intended app's visible accessible control labels and identity locally. Each permitted press requires review of its app, window and label, followed by a fresh target/permission check. This does not provide arbitrary desktop clicks, keyboard injection, saving or file dialogs. Listing and locating desktop controls requires Screen access. Screen OCR ignores Capri's panels and does not click its matches. These direct supported requests do not require sending screen/control contents to a conversation provider.

Chrome writes and presses require both Chrome access and Safe actions, plus per-action review. Detected password/payment/account/settings flows and protected labels are blocked. Controls replaced or moved during review cancel the operation. Website behavior is not fully described by accessible labels, and these checks are not a browser sandbox; inspect the review and use sensitive websites directly.

Avatar settings, provider selections, recent chat memory, explicitly saved notes and diagnostic logs are kept in Windows local application data. Packaged installations may use Windows' package-specific data location. Provider keys are protected using Windows user-level data protection. Chat memory and saved notes are not encrypted by Capri. Recent conversation history is bounded to 16 messages; explicit notes are limited to 32 entries of 500 characters each. “Remember that …” writes a note; “what do you remember about me?” shows notes, “clear saved notes” clears them, and Reset memory clears both notes and conversation history. Credential-like notes are refused and common provider key patterns are omitted from saved conversation text; this is not comprehensive secret detection. Saved notes can accompany subsequent ordinary conversations to the selected provider, including a cloud provider. Do not save sensitive information you do not want shared that way. Logs can include startup, error and local path information. No developer-operated conversation server or analytics collector is configured in this build.

Requested Word reports, papers, PowerPoint briefings and generated Notepad drafts search a fixed public English Wikipedia API endpoint using the requested topic, or use the visible article when you ask for a draft from this page. Wikipedia receives the topic and ordinary connection metadata; arbitrary source URLs, redirects, downloads and localhost fetches are not supported by this research path. Up to three lead excerpts are supplied to the selected local model, or to Groq/NVIDIA only after source-preview approval. This is excerpt-based research, not unrestricted web browsing or fact-checking. The draft, source links and scope are reviewed before you choose a local file destination or append the text to a verified blank Notepad tab. Reports, presentations and source snapshots are not added to conversation memory. Source authorship/license notices are included where applicable.

An explicit Google AI Mode request opens Google's official AI Mode page with the requested query. Google receives that query and ordinary browser/account metadata under its own terms. No AI Mode answer can grant Capri permissions or execute a desktop action. The separate Chrome read/share and reviewed-write controls still apply.

Use Reset memory to clear the app's remembered conversation. Disconnect cloud keys to stop using those providers. Turn off Mic Ears, Screen and Chrome independently. The portable build checks GitHub for releases; Store installations use Microsoft Store for application updates. Explicit model setup may contact the model/runtime hosts listed in the bundled notices; Store builds do not bootstrap a downloaded executable engine. Search commands use the relevant search website and its terms.
