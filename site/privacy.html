CAPRI PRIVACY & DATA

Privacy and data

Effective 28 October 2026. Publisher: regressorslove. This policy describes the Project Capri 1.4 Store review build, which is not yet publicly released. Earlier downloadable versions use different speech components and may have different controls.

Use at your own risk

Project Capri is experimental AI software. Speech recognition, generated replies and automated actions can be wrong or unexpected. The 1.4 agent tools block arbitrary terminal commands and executable downloads, and supported browser writes require review. These application-level guardrails are not a security sandbox or a guarantee of safety. The application runs with your Windows user permissions. Review actions, keep backups and enable only the capabilities you need. To the maximum extent permitted by applicable law, the software is provided as is, without warranties, and the publisher and contributors disclaim liability for losses or damage arising from its use. Non-waivable rights and liabilities remain unaffected. See the full use and liability notice. This notice does not change the data practices described below.

Microphone and local speech

The microphone starts only when enabled. Whistle recognizes speech locally, using memory and short-lived temporary audio files. Wake mode checks recognized utterances for “Capri”; it still needs microphone access while listening. Nano generates the two bundled voices locally. Full reference recordings are not uploaded.

Optional providers

Choosing Groq or NVIDIA sends conversations and recognized requests to that provider. Recent chat context may be included. Choosing ElevenLabs sends spoken reply text to its speech API. Provider privacy, retention and billing terms apply. Chrome page-analysis replies use local speech, including when ElevenLabs is selected.

Screen and Chrome

Screen access starts off. Enabling it permits window titles and OCR text to accompany conversation requests. Chrome access is separately off. Local previews and highlighting remain on the computer. For Groq/NVIDIA page analysis, the app previews a bounded snapshot and the exact destination, and requires “Send this page once” for every request. URL query strings and password controls are excluded; visible page text can still be personal. Analysis snapshots and replies are excluded from saved chat memory and cannot execute model action tags. Browser typing and clicking require review.

Local storage and controls

Settings, recent conversation memory and diagnostics are stored in Windows application data. Keys use Windows user-level protection; chat memory is not encrypted by Capri. Use Reset memory, disconnect provider keys, and switch off microphone, Screen or Chrome independently. No developer-operated conversation server or analytics collector is configured. Portable updates contact GitHub; Store updates use Microsoft Store. Explicit searches/model setup contact their corresponding services.

Contact and AI-content reports

Report an inappropriate AI reply or raise a privacy question. Reports are public by default; redact private text and never post keys. The app opens the form without sending your conversation automatically. For private support, privacy questions or AI-content reports, email regressorslove@outlook.com. Do not include API keys or passwords.
