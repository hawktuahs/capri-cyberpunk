// INTELLIGENCE MATRIX

Thinking Engines & LLM Setup

Capri's brain can run 100% locally on your computer, connect to free lightning-fast cloud APIs, or run offline with zero configuration.

Option A: Local Private Ollama (100% Free & Offline)

Zero API Keys • Complete Privacy • Unlimited Chats

Ollama lets you run open-source models completely locally on your GPU. Capri automatically detects when Ollama is running at http://localhost:11434 and hooks into it with zero configuration.

  1. Download & Install Ollama:

    Grab the Windows installer from the official website: ollama.com/download.

  2. Pull Your Favorite Model:

    Open Command Prompt or PowerShell and download Llama 3.1 or Qwen 2.5:

    Terminal
    ollama run llama3.1:8b

    For lower VRAM (4GB), try ollama run qwen2.5:3b or ollama run llama3.2:3b.

  3. Launch Capri Desktop:

    Start Capri using run.bat. Capri will find your local Ollama instance and begin conversing through it automatically!

Option B: Groq Cloud API (Free Tier • 500+ Tokens/sec)

Blazing Speed (<250ms) • Generous Free Daily Limits

Groq provides custom LPU hardware that generates responses at superhuman speeds. Their free tier gives you thousands of free requests daily on cutting-edge models like Llama 3.3 70B.

  1. Get a Free Groq API Key:

    Go to console.groq.com/keys, sign in with GitHub/Google, and click Create API Key.

  2. Copy your Key:

    Your key will look like gsk_.... Copy it to your clipboard.

  3. Paste into Capri's Cyberdeck Remote:

    Press Ctrl + Alt + C (or right click Capri's tray icon → Mainframe).

    Under Section 04: Cloud Brain Key, paste your gsk_... key, select llama-3.3-70b-versatile, and click Save.

Option C: NVIDIA NIM & OpenAI / OpenRouter

Frontier 70B & Nemotron Models

NVIDIA provides 1,000 free developer API credits for their enterprise NIM catalog (including Llama-3.1-70B-Instruct). You can also plug in standard OpenAI (sk-...) or OpenRouter (sk-or-...) keys.

  1. Get an API Key:

    Visit build.nvidia.com or openrouter.ai and create an API key.

  2. Enter in Cyberdeck Remote:

    Press Ctrl + Alt + C, paste your key into Cloud Key, type or select your model name (e.g. meta/llama-3.1-70b-instruct), and click Save.

Option D: Zero-Cost Offline Reflex (Cyberpunk Canon Lore)

No Keys • No Internet • Instant Replies

Don't have an API key or Ollama installed? Capri still works out of the box! Her built-in Cyberpunk Reflex Engine has hundreds of canon responses, time checks, screen analysis, and interactive PC commands.

  • Authentic Lore: Detailed answers about her creation, Night City, Arasaka, and Edgerunners canon.
  • Sassy Personality: Snarky netrunner remarks, affectionate praises ("Praise Capri" button), and quirky remarks.
  • PC Automation: Tell her to "search for Cyberpunk", "open YouTube", or "take a screenshot".
  • Screen Vision: "Look at my screen" triggers OCR analysis of active windows.

Update Mechanism

Capri includes a built-in release tracking system that keeps your desktop companion updated automatically.

How Automatic Updates Work

01
Daily Background Check:

On startup and once every 24 hours, Capri queries the GitHub Releases API (/releases/latest) for new version tags.

02
Windows Notification:

When a newer version (e.g. v1.2.1) is published, Capri displays a Windows notification: "Capri v1.2.1 is out — Click here to download."

03
1-Click Download:

Right-click the Capri tray icon at any time and click "Download Capri v1.2.1" (or "Check for updates") to immediately jump to the release page.
