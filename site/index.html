05 / A FEW THINGS TO KNOW

Before you plug in.

Do I need Python or a powerful graphics card?

The v1.3 full package includes its own speech runtime and English speech models. You don't need Python, CUDA, or a separate voice download. Local LLMs have separate memory requirements; cloud brains don't need a powerful GPU.

Is everything offline?

Bundled speech synthesis and English recognition work offline. Groq and NVIDIA conversations use the internet and send your conversation plus collected screen text to the provider. For local conversations, configure a local model. Web search and update checks also use the internet.

Can I use it without an AI key?

Yes. Use Ollama or the app's local model installer for AI conversation. Without either, Capri still animates and has a small set of scripted responses and commands.

Is this an official Cyberpunk app?

No. Capri Desktop is an unofficial fan project, based on the original desktop companion by lachydotmcg. Character artwork belongs to its respective owners.
